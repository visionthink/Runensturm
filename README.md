# Runensturm – Arena der Elemente

Ein Elementzauber-Spiel fürs Tablet (läuft direkt im Browser, am besten im Querformat).

**Spielen:** https://visionthink.github.io/runensturm/

## So geht's
- **Links ziehen:** laufen
- **Elemente antippen:** bis zu drei Elemente zu einem Zauber mischen (31 Zauber im Zauberbuch)
- **Rechts halten:** zaubern – nur halten zielt automatisch, ziehen zielt selbst
- **Nova:** stößt alle Gegner um dich herum weg

Tipps: Nasse Gegner trifft der Blitz doppelt. Nass + Frost friert sofort ein. Erde zerschmettert Eingefrorene.

Am Rechner: WASD/Pfeiltasten, Maus zum Zielen, Tasten 1–6 für Elemente, Leertaste für Nova.

Das ganze Spiel steckt in einer einzigen Datei: `index.html`.
